Brieflark

내 컴퓨터에서 돌아가는 개인 비서예요. 텔레그램으로 대화하고, 노트와 할 일을 내 폴더에 남기고, 아침마다 브리핑을 보내요.

어떻게 동작하나요

  • 비서는 사용자 본인의 Mac 또는 Windows PC에서 돌아가요. Brieflark 개발자가 운영하는 서버는 없어요.
  • AI는 사용자 본인의 Claude(또는 ChatGPT) 구독과 공식 프로그램을 써요.
  • Gmail·Google 캘린더·Google 드라이브는 사용자가 직접 만든 Google Cloud 프로젝트로, 사용자 본인 계정만 연결해요.
  • 메일 보내기·일정 만들기·파일 공유처럼 바깥에 영향을 주는 일은 텔레그램 승인 버튼을 누른 뒤에만 실행해요.

설치

설치는 Brieflark를 안내받은 분만 할 수 있어요. 설치 페이지의 복사 버튼으로 명령을 복사해 쓰세요. 설치 스크립트는 github.com/brieflark/install에 공개돼 있어요.

개인정보처리방침

Brieflark is a personal assistant that runs entirely on the user's own computer. There is no Brieflark server. Google data is accessed only by the user's own assistant through an OAuth client in the user's own Google Cloud project. Privacy Policy
