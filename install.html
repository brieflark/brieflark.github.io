Brieflark 설치

Brieflark 설치를 안내받은 분을 위한 페이지예요. 명령은 이 페이지의 '복사' 버튼으로만 복사해 주세요. 메신저로 받은 명령은 글자가 바뀌어 설치가 멈출 수 있어요.

설치 전에 GitHub 초대 메일의 수락을 눌러 두세요(초대받은 계정으로 로그인해야 해요).

Mac

  1. 터미널 앱을 열어요(Spotlight에서 "터미널" 검색).
  2. 아래 복사를 누르고, 터미널에 붙여 넣은 뒤 Enter. sudo는 붙이지 마세요.
  3. 화면 안내대로 단계마다 Enter. 중간에 멈춰도 같은 명령을 다시 붙여 넣으면 이어서 해요.

__bl_t=$(mktemp -t brieflark-install) && if curl -fsS -o "$__bl_t" 'https://raw.githubusercontent.com/brieflark/install/06413bbd8de7ffafb842c8abc53ec088b415ff1a/install.sh'; then { rm -f "$__bl_t"; if [ "$(shasum -a 256 <&4 | cut -c1-64)" = 'c2d552dfbea793cb0db292c838e614ec36c8437493d8c067e021a3374219f96d' ]; then /bin/bash /dev/fd/3; else echo '공지와 다른 파일이에요. 아무것도 실행하지 않았어요. 다시 하지 말고 안내한 사람에게 알려 주세요.' >&2; fi; } 3<"$__bl_t" 4<"$__bl_t"; else rm -f "$__bl_t"; echo '내려받지 못했어요. 인터넷 연결을 확인하고 같은 한 줄을 다시 붙여넣어 주세요.' >&2; fi

Windows

  1. 시작 메뉴에서 PowerShell을 열어요(관리자가 아닌 보통 창).
  2. 아래 복사를 누르고, PowerShell에 오른쪽 클릭으로 붙여 넣은 뒤 Enter.
  3. 화면 안내대로 진행해요. 멈추면 같은 명령을 다시 붙여 넣어요.

$u='https://raw.githubusercontent.com/brieflark/install/06413bbd8de7ffafb842c8abc53ec088b415ff1a/install.ps1';[Net.ServicePointManager]::SecurityProtocol=[Net.SecurityProtocolType]::Tls12;$b=(New-Object Net.WebClient).DownloadData($u);if(([BitConverter]::ToString([Security.Cryptography.SHA256]::Create().ComputeHash($b)) -replace '-','') -ne '6dea7829a03475da04923b182c65dacb92ba8e40fda17350cdb3f92927e04967'){throw '공지와 다른 파일이에요. 아무것도 실행하지 않았어요. 다시 하지 말고 안내한 사람에게 알려 주세요.'};iex ((New-Object Text.UTF8Encoding($false)).GetString($b))

안전장치

명령은 공개 설치 스크립트의 특정 버전을 받아, 내용이 명령에 적힌 지문(SHA256)과 같을 때만 실행해요. 다르면 아무것도 실행하지 않고 "공지와 다른 파일이에요"라고 멈춰요. 그때는 다시 하지 말고 안내한 사람에게 알려 주세요.
