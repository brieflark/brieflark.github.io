Brieflark 개인정보처리방침

시행일: 2026년 10월 22일

1. 요약

Brieflark는 사용자 본인의 컴퓨터에서만 동작하는 개인 비서 소프트웨어예요. Brieflark 개발자는 사용자의 개인정보나 Google 사용자 데이터를 수집·저장·전송·판매하지 않아요.

2. 다루는 정보와 저장 위치

  • Google 사용자 데이터(Gmail, Google 캘린더, Google 드라이브): 사용자가 직접 허용한 범위에서, 사용자 본인 컴퓨터의 비서가 사용자의 요청을 처리하려고 읽거나 씁니다. 접근 토큰은 사용자 컴퓨터에 본인만 읽을 수 있는 파일로 저장돼요.
  • 노트·할 일·브리핑: 사용자 컴퓨터의 볼트 폴더에 저장돼요.
  • 텔레그램 대화: 사용자가 만든 텔레그램 봇과 사용자 사이에서 오가요.

Brieflark 개발자가 운영하는 서버는 없고, 위 정보가 개발자에게 전달되지 않아요.

3. 제3자 서비스

사용자의 요청을 처리하는 과정에서 다음 서비스가 사용자 본인 계정으로 쓰여요. 각 서비스의 개인정보 처리는 해당 회사의 방침을 따라요.

  • AI 모델: Anthropic Claude 또는 OpenAI ChatGPT(사용자 본인 구독)
  • Telegram(대화 전달)
  • Google(Gmail·캘린더·드라이브, 사용자가 연결한 경우)

4. Google 사용자 데이터 사용 제한

Brieflark가 Google API에서 받은 정보를 쓰고 다른 앱으로 옮기는 방식은 제한적 사용(Limited Use) 요건을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다. Google 사용자 데이터는 사용자가 요청한 비서 기능에만 쓰이고, 광고에 쓰이거나 판매되지 않으며, 사람이 열람하지 않아요(사용자 본인 제외).

5. 사용자의 선택과 삭제

  • Google 연결은 언제든 Google 계정의 서드파티 액세스에서 끊을 수 있어요.
  • Brieflark를 지우면 컴퓨터에 저장된 토큰과 데이터도 함께 지울 수 있어요. 데이터는 모두 사용자 컴퓨터에 있으므로 사용자가 직접 관리해요.
